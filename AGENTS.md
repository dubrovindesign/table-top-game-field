# Правила для агента (стол + UI)

## Оверлеи на столе (DOM поверх канваса)

Элементы, которые визуально «лежат на поле» (слепая зона богов и аналогичные виджеты), должны вести себя как отрисовка на канвасе при **зуме камеры**:

- Размеры и позиции в **экранных пикселях** считать из мира через `boardWorldToScreen` / ту же модель, что и рендер.
- **Рамки, отступы и зазоры** между частями виджета задавать как `(базовое_значение_при_zoom_1) * camera.zoom` (или эквивалент через уже масштабируемые величины), а не фиксированные `px` в CSS, если нужно совпадение с юнитами, ландшафтом и т.д.
- Не полагаться на одну статическую толщину `border` в CSS для таких блоков, если зум меняется.

Исключения: чисто экранный UI (панель армии, меню), который не привязан к масштабу поля.
